# EduVision School Website Platform — User Manual

Version 1.2.0

## 1. Introduction

EduVision is a multi-tenant School Website Content Management System. Each school receives its own public website and secure admin dashboard. This manual is for school administrators, teachers and staff who manage a school site.

## 2. Logging In

1. Open your school admin URL, for example `https://admin.yourschool.eduvisionschools.co.za/admin/login` or `https://yourschool.eduvisionschools.co.za/admin/login`.
2. Enter your email and password.
3. Select your school from the list if prompted.
4. If two-factor authentication is enabled, enter the code from your authenticator app.

## 3. Dashboard

After login the admin dashboard shows:

- School overview and quick stats
- Latest notices and activity
- Links to manage content, media, users and settings

## 4. Managing Website Content

### Pages

- Go to **Pages** in the sidebar.
- Click **New Page**.
- Enter a title, slug (URL-friendly identifier) and content in Markdown.
- Choose whether the page appears in the public menu and set its order.
- Click **Save**.

### Posts / News

- Go to **Posts**.
- Click **New Post**.
- Add title, summary, content and an optional featured image.
- Select a category such as `news` or `events`.
- Publish or save as draft.

### Staff

- Go to **Staff**.
- Add staff members with name, role, department, photo, bio and contact details.
- Mark staff as published to show them on the public website.

### Events / Calendar

- Go to **Events**.
- Create events with start/end dates, location and category.
- Published events appear on the public calendar.

## 5. Media and Downloads

### Media Library

- Go to **Media Library**.
- Upload logos, photos, videos and PDFs.
- Allowed file types and maximum sizes are configured by the platform owner.

### Downloads

- Go to **Downloads**.
- Link a file from the media library or provide a URL.
- Add a title and category.

## 6. School Settings

- Go to **Settings**.
- Update school name, contact information, address and social links.
- Change primary and secondary colours.
- Upload a logo and favicon.
- Enable or disable dark mode by default.

## 7. Notices

- Go to **Notices**.
- Create a notice, choose the audience (All, Parents, Teachers, Learners, Staff) and publish.
- Notices appear on the public site filtered by audience.

## 8. Admissions

- Go to **Admissions**.
- View applications submitted through the public website.
- Update application status: Pending, Reviewing, Accepted, Rejected or Waitlisted.

## 9. Students, Results and Attendance

- **Students** — manage learner records, including parent contact details.
- **Results** — record subject scores per term and publish when ready.
- **Attendance** — mark daily attendance as Present, Absent, Late or Excused.

## 10. Users

- Go to **Users**.
- Add school staff, teachers or other administrators.
- Assign roles: School Admin, School Staff, Teacher, Parent or Learner.
- Deactivate users who no longer need access.

## 11. Password and Two-Factor Authentication

- From **Settings > Security**, change your password.
- Super admins can enable two-factor authentication by scanning the QR code with an authenticator app such as Google Authenticator or Authy.
- Save backup codes in a secure place.

## 12. Public Website

The public website automatically reflects all published content. Visit the school domain or subdomain to view:

- Home page with latest news, notices and events
- About, Principal's Message, Vision & Mission, History
- Staff, Academics, Admissions, School Fees, Uniform, Sports
- Gallery, News, Events, Downloads, Contact and Emergency Contacts

## 13. Troubleshooting

| Issue | Solution |
|-------|----------|
| Cannot log in | Check email, password and school selection. Reset password if needed. |
| Uploaded image not showing | Ensure the file is an allowed image type and the upload completed. |
| Page not appearing | Confirm the page is published and visible in the menu. |
| Site says subscription inactive | Contact the platform owner or super admin. |

## 14. Support

For technical support, contact the platform owner or super admin listed in your school settings.
